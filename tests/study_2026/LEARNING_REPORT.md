## 一、学习项目清单及核心亮点

### 1. Microsoft Qlib (⭐ 42.6K, 持续活跃)

| 项目 | 详情 |
|------|------|
| 仓库 | https://github.com/microsoft/qlib |
| 语言 | Python |
| 许可证 | MIT |
| 最后更新 | 2026-04-22 |

**核心亮点**:

1. **声明式表达式引擎** — 用 DSL 定义因子，无需手写 pandas 循环。例如 `Ref($close, -20) / $close - 1` 即可表达 20 日反转因子。底层自动展开为高效 pandas 操作。

2. **Alpha158/Alpha360 因子库** — 预置 158/360 个 Alpha 因子，覆盖动量、反转、波动率、换手率、流动性、估值、技术指标等维度，支持数据集级别的归一化和预处理管道。

3. **Model Zoo 统一接口** — 模型训练接口统一，内置 LightGBM、XGBoost、CatBoost、LSTM、GRU、Transformer、TabNet 等，一键切换。

4. **RD-Agent 自动化因子挖掘** — LLM 驱动的自动化量化研究框架，可自动完成因子挖掘、模型选择和超参优化。

5. **高性能数据存储** — 二进制格式存储，支持按时间/品种高效切片，配合表达式引擎实现惰性计算。

---

### 2. QUANTAXIS (⭐ 25K+)

| 项目 | 详情 |
|------|------|
| 仓库 | https://github.com/yutiansut/QUANTAXIS |
| 语言 | Python + Rust |
| 许可证 | MIT |
| 最后更新 | 2026-02-28 |

**核心亮点**:

1. **Rust+Python 混合架构** — 性能关键路径（账户结算、数据处理、撮合引擎）用 Rust 实现，Python 侧通过 PyO3 调用，兼顾性能与开发效率。

2. **QIFI 协议** — 标准化的跨语言账户/订单/持仓协议，定义了统一的 JSON 消息格式，支持微服务间通信。

3. **零拷贝数据桥** — 共享内存机制实现 Python-Rust 之间的高效数据传输，避免序列化开销。

4. **优雅降级模式** — `try-import-fallback` 模式：当 Rust 核心未安装时自动回退到纯 Python 实现，保证基本功能可用。

5. **微服务架构** — 数据服务、策略服务、风控服务、订单服务独立部署，通过消息总线通信。

---

### 3. backtesting.py (⭐ 7K+)

| 项目 | 详情 |
|------|------|
| 仓库 | https://github.com/kernc/backtesting.py |
| 语言 | Python |
| 许可证 | AGPL-3.0 |
| 最后更新 | 2024 (活跃) |

**核心亮点**:

1. **极简策略 API** — 策略只需继承 `Strategy` 基类并实现 `init()` 和 `next()` 两个方法，极大降低上手门槛。

2. **向量化订单匹配** — 使用 NumPy 向量化操作进行订单撮合，在纯 Python 生态中实现高速执行。

3. **交互式可视化** — 集成 Bokeh/Plotly，生成可缩放、标注的权益曲线和交易标注图表。

4. **内置参数优化** — 网格搜索 + 热力图，直接可视化不同参数组合的绩效对比。

## 三、已完成的验证测试及结论

### 测试 1: 声明式因子表达式引擎

**测试文件**: `tests/study_2026/test_expression_engine.py`

| 测试项 | 结果 | 说明 |
|--------|------|------|
| 反转因子正确性 | ✅ PASS | 与硬编码完全一致, 相关系数 1.000 |
| 波动率因子正确性 | ✅ PASS | 与硬编码完全一致 |
| 量比因子正确性 | ✅ PASS | 相关性 0.94 (差异源于 min_periods 参数) |
| 动量因子正确性 | ✅ PASS | 5/10/20/60 日全部通过 |
| 复合表达式 | ✅ PASS | 复合表达式正常执行 |
| 编译缓存 | ✅ PASS | 二次访问加速 55x |
| 性能对比 | ✅ PASS | 7.5x 开销换取灵活性 |

**结论**:
- 表达式引擎的概念验证通过，核心算子 (Ref, Mean, Std, PctChange 等) 计算正确。
- 当前原型有 ~7.5x 性能开销（主要来自逐股分组循环），可通过以下方式优化：
  - 将算子实现为 pandas groupby+transform，消除分组循环
  - 使用 JIT 编译或 Numba 加速
- **建议**: 可以在 factor-engine 中引入表达式引擎作为因子定义的**可选 DSL**，与现有硬编码方式并存。性能优化后再作为主推方式。

### 测试 2: 向量化回测引擎

**测试文件**: `tests/study_2026/test_vectorized_backtest.py`

| 测试项 | 结果 | 说明 |
|--------|------|------|
| 正确性验证 | ✅ PASS | 权益曲线相关性 0.9947，所有绩效指标差异 < 0.5% |
| 可扩展性 | ✅ PASS | 50 股 35x, 200 股 47x, 500 股 51x 加速 |
| A 股规则 | ✅ PASS | T+1、涨跌停限制正确生效 |

**结论**:
- 向量化回测引擎实现了与逐行回测高度一致的权益曲线 (相关性 0.9947)。
- 性能提升显著: **35-51 倍加速**，且随股票数量增加加速比提升。
- A 股特有规则 (T+1 买入次日可卖、涨跌停无法成交) 验证通过。
- **建议**: 可将向量化引擎作为 backtest-engine 的 `native_adapter` 的替代实现，在因子回测和参数优化等高频场景中使用。实盘级回测仍可保留现有逐行适配器以保证精度。

| 测试项 | 结果 | 说明 |

## 四、待用户确认的优化建议

### 优先级分类

| 优先级 | 优化项 | 实施难度 | 预期工时 | 风险 |
|--------|--------|----------|----------|------|
| P0 - 高 | 向量化回测引擎集成到 backtest-engine | 低 | 1-2 天 | 低: 已验证正确性 |
| P1 - 中 | 扩展因子库集成到 factor-engine | 低 | 0.5 天 | 低: 无破坏性改动 |
| P2 - 中 | 声明式表达式引擎引入 factor-engine | 中 | 2-3 天 | 中: 需性能优化后上线 |
| P3 - 低 | Rust 核心加速 (借鉴 QUANTAXIS) | 高 | 5-10 天 | 高: 引入 Rust 工具链 |
| P4 - 低 | 策略 API 简化 | 中 | 2-3 天 | 中: 涉及 API 变更 |

### 推荐实施路径

1. **第一阶段** (本期): 集成向量化回测 → 集成扩展因子库（两项均为低风险高收益）
2. **第二阶段** (下期): 表达式引擎性能优化 → 引入 factor-engine
3. **第三阶段** (远期): Rust 加速核心 → 策略 API 重构
